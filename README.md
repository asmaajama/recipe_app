# Recipe App

A PHP & MySQL web application for browsing, saving, and managing recipes.

## Features
- User registration & login with session handling
- Add, view, and favorite recipes
- Image uploads for recipe photos
- Client-side form validation (JavaScript)

## Tech Stack
PHP · MySQL · HTML5 · CSS3 · JavaScript

## Setup
1. Import `recipe_app.sql` into phpMyAdmin
2. Update credentials in `includes/db.php`
3. Place the folder in `htdocs` and run via XAMPP
